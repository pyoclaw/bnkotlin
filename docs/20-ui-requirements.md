# UI Requirements

## Customer

### Home
- Brand-led hero
- Open/closed state
- Current estimated wait
- Featured products
- Menu CTA

### Menu / Product
- Categories and search
- Product cards
- Quick add
- Images
- Modifiers and extras
- Allergens/dietary labels
- Live price

### Cart / Checkout
- Editable items
- Pickup time
- Notes
- Contact details
- Payment
- Order summary

### Tracking
- Order number
- Live state
- ETA
- Timeline
- Delay messaging

## Kitchen

- Active queue
- New order emphasis
- Large order cards
- ETA
- Accept / reject / delay / ready / complete
- Connectivity indicator

## Admin

- Orders
- Menu
- Availability
- Opening hours
- Settings
- Basic reporting

## Accessibility

Target WCAG 2.2 AA for customer-facing surfaces. Provide keyboard navigation where applicable, visible focus, sufficient contrast, semantic labels, suitable touch targets, and status communication that does not rely on color alone.
