# Architecture Decisions

## Approved

- Kotlin-first end-to-end
- Compose Multiplatform for shared UI
- Ktor backend
- PostgreSQL source of truth
- WebSockets for realtime sync
- Offline-first kitchen behavior
- Payment provider abstraction

## Rejected

- React / Next.js as the primary frontend stack
- SaaS ordering lock-in
- Payment logic inside the UI
- Multiple frontend ecosystems without a strong reason
