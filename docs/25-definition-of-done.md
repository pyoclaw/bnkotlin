# Definition of Done

A feature is complete when:

- shared domain rules are implemented once
- client and server validation exist
- API contracts are typed
- persistence/migrations exist
- required realtime events are defined
- offline behavior is specified for operational flows
- critical paths are tested
- failures are visible and actionable
- authorization is enforced
- production logging/metrics exist where needed
- UI follows the design system
- relevant accessibility requirements are met
- documentation is updated
