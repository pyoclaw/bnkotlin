# Vision

Brød & Fyld Next is a Kotlin-first restaurant operating platform. It replaces the current outdated ordering flow with a premium, realtime, pickup-first experience that works across customer devices, kitchen tablets, and admin screens.

The product should feel:
- fast
- clean
- local
- reliable
- realtime
- restaurant-owned

This is not a generic webshop. It is a restaurant operating system.
