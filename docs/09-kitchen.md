# Kitchen

## Goals

- Minimal taps
- Clear queue
- Large touch targets
- Fast status changes
- Offline resilience

## Features

- Live incoming orders
- Accept / reject / delay / ready / complete
- New order sound
- Manual ETA adjustment
- Optional print routing
- Visible sync status

## Rules

- New orders must appear instantly.
- Delays must show the new ready time.
- Completed orders must leave the active queue.
- Rejected orders must include a reason.
- The kitchen must remain usable during temporary connectivity loss.
